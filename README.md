# THE KING OF AZTLAN 🕹️🔥

Motor de videojuego de peleas 2D Pixel-Art a **60 FPS** inspirado en las mecánicas clásicas de **The King of Fighters 2002 (Neo-Geo MVS)**.

## ✨ Características Principales
- **Combates por Equipos 3 vs 3**: Selecciona tus 3 peleadores entre **42 personajes** organizados en los **11 Equipos Oficiales**, **8 Personajes Edit** y el Jefe Final **Omega Rugal**.
- **Modo Torneo Arcade de 12 Niveles**: Enfréntate a los 11 equipos oficiales hasta llegar al Nivel 12 contra **Omega Rugal**.
- **Mecánicas Auténticas KOF 2002**:
  - Caminata, carrera (`66`), retroceso (`44`), Salto Corto (*Short Hop*), Salto Normal y Salto Largo (*Hyper Hop*).
  - Rodada defensiva / Evasión (`AB` / `J` / `LB`).
  - Sistema de combos encadenados: `Ataque Débil -> Ataque Fuerte -> Golpe de Comando (6+A / 6+B) -> Especial -> Desesperación (Super Cancel)`.
  - Barra de Poder de hasta **3 Stocks**, **Modo MAX (`BC`)** con *Free Cancels*, **Desesperaciones (`DM`)** y **MAX Desesperaciones (`SDM`)**.
- **Soporte Completo de Controles**:
  - **Teclado Local (1P y 2P)**.
  - **Mandos USB / Bluetooth** (Xbox, PlayStation, Switch Pro, Fightsticks Arcade) mediante HTML5 Gamepad API.
  - **Multijugador en Línea (P2P 1 vs 1)** por Código de Sala (`WebRTC DataChannels` + `BroadcastChannel`).
- **Banda Sonora Original**:
  - Menús y Selección: `Tournament_Grand_Finale.mp3`
  - Combates: `Last_Credit_Standing.mp3`

## 🚀 Cómo Jugar
Abre `index.html` directamente en cualquier navegador moderno o despliega el repositorio en **Vercel / GitHub Pages**.
